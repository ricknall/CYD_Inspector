# CYD Inspector v1.3.0

This source overlay adds confirmed CYD2USB touchscreen support. It enables
mapped touch and five-point calibration for both supported board profiles.
Each profile uses a separate saved calibration namespace.

## Install and build

1. Back up or commit the current project.
2. Extract this ZIP into the existing `CYD_Inspector` project folder and
   allow the seven source/header files to be replaced.
3. Build and upload the `cyd2usb` PlatformIO environment.
4. Open the serial monitor at 115200 baud and enter `profile 2`.

## Test sequence

1. Enter `report`. Confirm the firmware line says `1.3.0` and the CYD2USB
   RGB, light, and speaker
   mappings are reported as `NOT TESTED`.
2. Enter `calibrate` and tap the five displayed targets in order, briefly
   holding and releasing each one.
3. Confirm that calibration completes, reports a sensible center check, and
   says `Saved across resets: YES`.
4. Enter `touch` and tap the four corners and center. Confirm the screen
   coordinates and visible X marks follow the touches.
5. Enter `touch` again to stop.
6. Reset the board, enter `report`, and confirm `Calibration saved: YES`.

The lower-level `touch irq` and `touch probe` commands remain available as
diagnostics. Paste the calibration and mapped-touch output into our
conversation.
