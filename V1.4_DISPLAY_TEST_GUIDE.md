# CYD Inspector v1.4.0 display validation

This test determines the configuration a weather application should use. It
records electronic ID readback separately from a visually confirmed working
driver, because some CYD displays do not return a useful controller ID.

## Build and upload

1. Open this extracted folder in VS Code. The folder containing
   `platformio.ini` must be the project root.
2. Build and upload with PlatformIO.
3. Close any other program using the board's COM port, then open Monitor at
   115200 baud.

## Test one board

Select the physical board family first:

```text
profile 1
```

for the classic single-USB board, or:

```text
profile 2
```

for the two-USB CYD2USB board.

Then run:

```text
display probe
display test ili9341
```

Photograph the screen or record whether all of these are true:

1. A white border is visible on all four edges.
2. Text reads normally from left to right.
3. The three bars are red, green, and blue in that order.
4. The background is black and the white text is not inverted.

Next run:

```text
display test st7789
```

Record the same four observations. Do not confirm either profile until both
tests have been compared.

If the ILI9341 test is the correct one, enter:

```text
display confirm ili9341
```

If the ST7789 test is the correct one, enter:

```text
display confirm st7789
```

Finally enter:

```text
display
```

Copy the complete serial output. It includes the electronic readback, the
visual-test conclusion, and a ready-to-copy TFT_eSPI configuration for a
weather application.

## Clearing a mistaken confirmation

```text
display clear
```

This removes only the saved visual display result for the selected board
profile. It does not clear the board selection or touch calibration.
