CYD Board Inspector

Install the hardware diagnostic utility on a compatible ESP32 Cheap Yellow Display directly from Chrome or Edge on a desktop computer.

This installation erases the board. Existing firmware and its saved settings will be replaced.
  1. Connect the CYD with a data-capable USB cable.
  2. Close PlatformIO Serial Monitor and other programs using its COM port.
  3. Select Install CYD Board Inspector below.
  4. Choose the CYD serial port when the browser asks.
This browser cannot install over Web Serial. Use desktop Chrome or Edge.

After installation, use the installer dialog's logs and console at 115200 baud, or reconnect with a serial terminal.

Source code and documentation: GitHub repository.
