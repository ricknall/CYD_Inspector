CYD Board Inspector

Version 1.4.0 — display identification and app configuration

Install the hardware diagnostic utility directly from desktop Chrome or Edge. This version electronically identifies supported display controllers, provides visual driver tests, and prints application-ready TFT_eSPI settings. The tested classic single-USB and CYD2USB boards both identify as ILI9341 and use the ILI9341_2 application driver. Confirmed touchscreen support and independent persistent calibration are retained.

This installation erases the board. Existing firmware and saved settings, including prior touch calibration, will be replaced.
  1. Connect the CYD with a data-capable USB cable.
  2. Close PlatformIO Serial Monitor and anything else using its COM port.
  3. Select Install CYD Board Inspector v1.4.0.
  4. Choose the CYD serial port when the browser asks.
This browser cannot install over Web Serial. Use desktop Chrome or Edge.

After installation, connect a serial terminal at 115200 baud and type help. Select profile 1 for the classic single-USB board or profile 2 for the two-USB board. Type display for the detected controller and application settings, then run calibrate for that physical screen.
