CYD Board Inspector

Version 1.2.0 — classic single-USB CYD

Install the hardware diagnostic utility directly from desktop Chrome or Edge. This version includes persistent touch calibration and confirmed RGB LED, light-sensor, and speaker mappings for the tested classic single-USB CYD.

This installation erases the board. Existing firmware and saved settings, including prior touch calibration, will be replaced.
  1. Connect the CYD with a data-capable USB cable.
  2. Close PlatformIO Serial Monitor and anything else using its COM port.
  3. Select Install CYD Board Inspector v1.2.0.
  4. Choose the CYD serial port when the browser asks.
This browser cannot install over Web Serial. Use desktop Chrome or Edge.

After installation, connect a serial terminal at 115200 baud and type help. Use profile 1 for the classic single-USB board, then run calibrate for that physical screen.
